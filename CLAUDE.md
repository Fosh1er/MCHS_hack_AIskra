## Дополнительно для Claude Code
- Перед изменениями читайте спецификацию пункта в `specs/` и связанные ADR. После реализации обновите в ней трассировку.
- После правок бэкенда: `make be-check`; фронтенда: `make fe-build`. Не сообщайте об успехе без зелёных проверок.
- Коммитить и пушить — только по явной просьбе пользователя.
