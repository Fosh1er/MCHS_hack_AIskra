# АИскра — сценарии ручного тестирования: оператор и преподаватель

Полный список того, что может сделать пользователь, в виде проверок «действие → что должно быть». Порядок: сначала обучающийся (оператор 112 и диспетчер ДДС), потом преподаватель, в конце — сквозное занятие втроём и отказы.

Каждый пункт отмечайте ✅ или ❌ и пишите номер issue. Приоритеты — как в [bugbash.md](bugbash.md): P0 ломает показ или теряет данные, P1 — функция не работает, P2 — работает с обходом или выглядит плохо, P3 — мелочь.

---

## 0. Подготовка

### 0.1 Стенд
- Режим `AISKRA_APP_ENV=demo`, свежий `main`, данные: `demo-seed` + `demo-history`.
- **ИИ.** Чтобы проверить живые ответы и голос Gemini, нужен ключ OpenRouter с **положительным балансом**. Без денег на счёте платные модели отвечают 402, и тренажёр уходит в «ответ по правилам». Это тоже нужно проверить, но отдельно (раздел 7).
- **Голосовой ввод** работает только по https или на `localhost`.

### 0.2 Учётки
Вход одной кнопкой на странице входа, пароль не нужен.

| Логин | Роль | Для чего |
|---|---|---|
| `op1`, `op2` | обучающийся | оператор 112 |
| `dds1` | обучающийся | диспетчер «Служба 101» (пожарная) |
| `dds2` | обучающийся | диспетчер «Служба 103» (скорая) |
| `teacher` | преподаватель | банк сценариев, занятия, отчёты |
| `admin` | администратор | только по паролю, на кнопках входа его нет |

### 0.3 Как удобнее
- Три окна в разных профилях браузера (или обычное + инкогнито + другой браузер): `teacher`, `op1`, `dds1`. В одном профиле вход перезапишет сессию.
- Экран АРМ — от 1280 px. Кабинеты проверяйте и на телефоне (375 px).
- Консоль браузера (F12) держите открытой: ошибок JavaScript, CSP и ответов 5xx быть не должно.
- Гарнитура для голосовых проверок; один прогон «без рук» — через динамики.

### 2.3 Эмоции заявителя — проверочные фразы
Подпись у реплики показывает эмоцию; в разборе разговора (2.8.4) видно, что сработало. Проверяйте **по одной фразе за реплику**.

| # | Фраза оператора | Ожидаемо | ✓ |
|---|---|---|---|
| 2.3.1 | «Я вас слышу, помощь уже едет» | Напряжение снижается, ответ спокойнее; в разборе — «успокоил» (зелёным) | |
| 2.3.2 | «Оставайтесь на линии» / «Не кладите трубку» | Снижает напряжение | |
| 2.3.3 | «Успокойтесь!» / «Не кричите» | Напряжение растёт, доверие падает; в разборе — «обесценил» (красным) | |
| 2.3.4 | «Быстрее!» / «Мне некогда» / «Не тяните» | Растёт; в разборе — «давил» | |
| 2.3.5 | Одну и ту же успокаивающую фразу три раза | Работает только первый раз | |
| 2.3.6 | Подряд несколько грубостей | Заявитель может перестать сотрудничать или положить трубку: «Заявитель положил трубку. Перезвоните ему по номеру АОН.» | |

> Известное расхождение (20.10): **при психологическом профиле** фразы давления («мне некогда», «быстро отвечайте на вопрос») не распознаются, а «Быстрее говорите, не тяните! Адрес какой?» засчитывается как «короткий вопрос по делу». Без профиля правило работает. Проверьте и отметьте.
