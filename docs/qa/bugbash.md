# Баг-баш перед финалом (F6.8)

Ручная проверка, которую не заменяют автотесты: живой голос, реальные браузеры, глазами человека. Проходит человек, который не писал код. Найденное заводится как issue с меткой `bug` и приоритетом:
- **P0** — ломает показ или теряет данные;
- **P1** — функция не работает, обхода нет;
- **P2** — работает с обходом или выглядит плохо;
- **P3** — мелочь.

К финалу открытых P0 и P1 быть не должно.

Стенд — режим `demo`, свежий `main`, данные `demo-seed` + `demo-history`. Каждый пункт отмечается ✅ / ❌ (номер issue).

## 0. Окружение
| Браузер | ОС | Ширина |
|---|---|---|
| Chrome (последний) | Windows 10/11 | 1366, 1920 |
| Яндекс Браузер | Windows | 1366 |
| Firefox | Ubuntu 22.04+ | 1366 |

На каждом экране открыта консоль: ошибок JavaScript и CSP быть не должно.

## 1. Вход
- [ ] Страница входа: лента «Демонстрационный стенд», карточки ролей; «Войти» ведёт в нужный кабинет.
- [ ] Вход по паролю, неверный пароль — понятная ошибка; после серии ошибок — временная блокировка.
- [ ] Выход; повторный вход; истёкшая сессия — возврат на вход без «белого экрана».
- [ ] Прямая ссылка на чужую карточку или звонок другого обучающегося — 404 или «нет доступа», данные не видны.

## 2. Преподаватель
- [ ] Банк сценариев:
  - генерация;
  - фильтры, включая «с психологическим профилем» и «ветвление»;
  - карточка сценария, граф ветвления;
  - полное и частичное утверждение.
- [ ] Занятие:
  - роли участников;
  - психологический модификатор (профили, интенсивность, вес);
  - ветвление (вес);
  - старт и стоп.
- [ ] Мониторинг: плитки участников обновляются, состояние заявителя видно.
- [ ] Отчёт занятия:
  - тепловая карта;
  - «Типичные ошибки работы со стрессом»;
  - «Развитие ситуаций»;
  - черновик отзыва и сохранение;
  - CSV и XLSX.
- [ ] Аналитика, допуск, протокол на печать.
- [ ] «Методика»: 15 профилей, ссылки на источники открываются.

## 3. Оператор 112
- [ ] Журнал, входящий учебный вызов, «Ответить».
- [ ] Разговор текстом:
  - ответ печатается по мере генерации;
  - под ответом строка «ИИ · модель · первое слово … · ответ …»;
  - без модели — «ответ по правилам».
- [ ] Голос:
  - первая фраза звучит до конца генерации;
  - голос соответствует состоянию заявителя (паника — быстро и громко);
  - выключатель «голос» работает.
- [ ] Кнопка «говорить»: запрос микрофона; отказ в доступе — понятное сообщение; распознанная реплика уходит заявителю.
- [ ] «Без рук»:
  - в наушниках — без эха;
  - через динамики — эхо заявителя не принимается за реплику оператора;
  - перебивание: оператор заговорил — заявитель замолк.
- [ ] Звонок с профилем «паника»: шкала ECCS растёт на «успокойтесь!» и снижается на «я на линии, помощь уже едет»; «пауза» останавливает звонок.
- [ ] Звонок с ветвлением:
  - молчание 40–60 с — ситуация развивается (реплика-событие);
  - итог и путь видны в разборе.
- [ ] Карточка 112:
  - адрес из подсказок и с карты;
  - тип по классификатору, опросная карта, службы на панели;
  - сохранение, горячие клавиши, таймер.
- [ ] Панель оценки: баллы, ошибки с объяснениями, блоки «Работа с заявителем» (источники кликабельны) и «Развитие ситуации».

## 4. Диспетчер ДДС
- [ ] Очередь с таймерами; «Принята» с номером наряда и бригадами; занятые бригады недоступны.
- [ ] Звонок старшему группы, ответ зависит от развития ситуации.
- [ ] Статусы до «Работы завершены»; запись звонка WAV скачивается и звучит.

## 5. Администратор
- [ ] Пользователи: создать, заблокировать, сбросить пароль; группы.
- [ ] Настройки: значения занятий по умолчанию, ежедневная копия.
- [ ] Резервная копия → восстановление на копии базы.
- [ ] Состояние: подсистемы, остановка и запуск, оповещения о сбоях; журнал аудита (демо-вход виден как «Вход на демо-стенде без пароля»).

## 6. Голосовой полигон
- [ ] Страница из меню кабинета открывается, микрофон по https.
- [ ] Разговор, ответ потоком, озвучка, перебивание.

## 7. Отказы (на стенде, с предупреждением команды)
- [ ] Модель недоступна (неверный ключ или адрес): звонки идут, ответы «по правилам».
- [ ] Синтез недоступен: реплики озвучивает браузер.
- [ ] Перезапуск backend посреди занятия: черновик карточки сохранён, звонок открывается.
- [ ] Обрыв сети на 30 с: карточка сохраняется после восстановления.
