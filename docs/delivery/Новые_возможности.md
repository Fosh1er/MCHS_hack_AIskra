## Заявитель, похожий на живого человека

### Эмоциональный голос собеседника (п. 3.6)
- **Состояние заявителя меняется от тона оператора.** Эмоция, напряжение, доверие и готовность отвечать задаются по шкале 0–10:
  - начальное состояние — по сложности сценария и группе происшествия: пожар — паника, ДТП — шок, коммунальная авария — раздражение;
  - «я вас слышу», «помощь уже едет», «оставайтесь на линии» снижают напряжение;
  - «успокойтесь», «быстрее говорите» повышают его;
  - успокоить одной длинной фразой нельзя: правило срабатывает один раз на реплику, успокаивающая фраза — один раз за звонок.
- **Голос следует состоянию:**
  - в браузере — темпом, высотой и громкостью;
  - серверный синтез — голосом роли (женский или мужской заявитель, старший группы, диспетчер службы). На демо — Gemini TTS через OpenRouter, эмоция передаётся стилем; в контуре заказчика — Piper в Speaches на CPU.
- **Разговор без рук:**
  - микрофон слушает весь звонок, фразы распознаются Whisper;
  - оператор может перебить заявителя: тот замолкает;
  - эхо реплики заявителя отсекается;
  - на сервер уходят только готовые фразы, звук не хранится.
- **Преподавателю:**
  - разбор разговора — график напряжения заявителя по репликам и слова, которые его изменили;
  - состояние заявителя на плитке мониторинга;
  - информативный критерий «Работа с заявителем» в автооценке;
  - режим звонка (текст, голос, без рук) в отчёте.

### Психологический модификатор (п. 3.7)
- **Что это.** Преподаватель включает модификатор в занятии: доля звонков, профили, интенсивность, вес в итоге. Можно и закрепить профиль за сценарием. Заявитель получает психологическое состояние из 15 профилей:
  - острые стрессовые реакции по перечню ЦЭПП МЧС России: страх и паника, плач, истерика, агрессия, тревога, апатия, ступор, психомоторное возбуждение, горе и вина;
  - кризисные состояния: бред, суицидальные высказывания;
  - особые заявители: ребёнок, пожилой, опьянение, ложный вызов.
- **Состояние ведёт детерминированный движок, модель только «играет» его:**
  - уровень по шкале ECCS IAED 1–5;
  - запрещённое действие поднимает уровень сразу, успокоение требует нескольких правильных действий подряд;
  - в панике заявитель не может назвать адрес, пока оператор его не «вернёт».
- **Голос и оценка видят одно состояние.** С профилем эмоциональный голос п. 3.6 выводится из состояния модификатора, и синтез озвучивает именно его.
- **Отдельный блок оценки «Работа с заявителем в стрессе»:**
  - 11 критериев: контакт, адрес под стрессом, ответ на эмоцию, приёмы для состояния, недопустимые действия, речевой стандарт, инструкции, решение о психологе и службах, деэскалация, ИИ-судья тона, спокойствие в голосе;
  - лента разбора: реплика → действия ✓ и ✗ с объяснением и источником → изменение состояния;
  - по умолчанию в итог не входит, преподаватель может задать вес.
- **Безопасность обучающихся.** Тяжёлые профили (суицид, ребёнок) включает только преподаватель. Перед звонком — предупреждение, в звонке — кнопка «пауза», остановка пишется в журнал аудита.
- **Основания:**
  - профстандарт 12.002 (приказ Минтруда № 681н);
  - пособия ЦЭПП МЧС 2012 и 2023;
  - «Первая помощь» Минздрава 2025;
  - ПП РФ № 1931;
  - шкала ECCS IAED;
  - APCO/NENA ANS 1.107.2-2025, NENA-STA-001.

  Около 100 проверенных источников — в [docs/research/psychology](../research/psychology/00_README.md).
- **Проверено:** бенчмарк мутаций 12 из 12; сквозной звонок в браузере с профилем «Плач».

## Преподаватель

### Отзыв по занятию с черновиком от ИИ (п. 4.7)
- **Черновик.** В отчёте занятия у строки обучающегося — «предложить отзыв». ИИ пишет черновик по фактам занятия: итог → что получилось → что подтянуть (не больше трёх) → следующий шаг. Структура — по Hattie & Timperley (2007), без сравнения с другими (Shute, 2008).
- **Без модели** черновик строится по правилам из тех же фактов. В модель не уходят ФИО и название занятия.
- **Отзыв пишет преподаватель:** правит и сохраняет, сохранение пишется в журнал аудита. Обучающийся видит отзыв в истории занятий. Следующий черновик показывает «было → стало» по прошлым «подтянуть».

### Подсказки по интерфейсу для нового преподавателя (п. 5.4)
- Обзор маршрута при первом входе и подсказки на тех экранах, где преподаватель рискует ошибиться: банк сценариев и утверждение, занятие с ролями, мониторинг, отчёт и экспертная правка, тепловая карта, аналитика, допуск.
- Какие экраны получили подсказки и почему — таблица 7.1 [спецификации 5.4](../../specs/5.4-teacher-onboarding.md).

## Обучающийся

### Подсказки по интерфейсу для нового обучающегося (п. 5.3)
- При первом входе — обзор; на каждом экране — пошаговая подсветка кнопок: кабинет, журнал 112, карточка 112, выбор службы ДДС, реестр и карточка ДДС.
- Инструкцию можно пропустить в любой момент или пройти заново. Прогресс хранится на сервере за учётной записью.
- **Учебный таймер не идёт, пока новичок впервые читает подсказки:** время карточки 112 и время решения ДДС считаются без этой паузы. Пауза — не больше 10 минут, каждая пишется в аудит.

### Голосовой ввод (п. 1.4)
- Кнопка «говорить» в панели звонка: реплика распознаётся Whisper — локально на GPU или CPU, либо через API на демо-стенде. Дальше — как текстовая реплика, темы опроса засчитываются в автооценку.
