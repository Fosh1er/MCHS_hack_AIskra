# 0006. Кеш ответов ИИ как декоратор порта

- **Статус:** Принято · **Дата:** 2026-09-26 · **Пункты плана:** 0.1, 3.3, 3.4

## Контекст
На CPU вызов модели занимает секунды–десятки секунд. Группа обучающихся задаёт одинаковые вопросы по одному сценарию; оценка одинакового текста должна быть одинаковой.

## Решение
- **`CachingLLM` / `CachingTTS`** реализуют те же порты и оборачивают любой адаптер (`ai/adapters/caching.py`). Хранилище — порт `CachePort`, сейчас `InMemoryTTLCache`.
- **Режимы (в конфиге задачи):**
  - `exact` — ключ по всему запросу; при temperature > 0 без seed кеш не используется;
  - `task` — ключ `(scope, нормализованный последний вопрос)`, `scope` передаёт вызывающий код (например, id сценария + раскрытые факты);
  - `off`.
- **Не кешируются** ошибки и невалидный вывод. В ключ входят модель и `prompt_version`, поэтому смена промпта обходит старые записи.
- **Single-flight:** одинаковые одновременные запросы ждут один вызов модели.
- **В ключе только хеш:** тексты обучающихся не хранятся.

## Последствия
- Мгновенные повторные ответы, одинаковые условия для группы, стабильная оценка.
- Перезапуск процесса очищает кеш. Позже — адаптер `PostgresCache` без изменения вызывающего кода.
