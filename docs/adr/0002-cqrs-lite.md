# 0002. CQRS-lite: команды и запросы без шин

- **Статус:** Принято · **Дата:** 2026-09-26 · **Пункты плана:** 0.1

## Контекст
Полноценный CQRS (шины, отдельная read-БД, event sourcing) избыточен для MVP. При этом разделение чтения и записи делает код понятным и ускоряет экраны-реестры.

## Решение
- **Раздельные папки:**
  - `application/commands/` — `Command` + обработчик, меняет состояние через репозиторий и UoW (сессия SQLAlchemy);
  - `application/queries/` — `Query` + DTO + обработчик, только чтение простым SQL или ORM в DTO, минуя агрегаты.
- **Шин, медиатора, outbox и доменных событий как инфраструктуры нет.** Обработчик вызывается из API напрямую. Реакции (аудит, уведомления) вызываются явно в обработчике команды.
- **Вызов внешнего сервиса с побочным эффектом** (модель, запись в кеш) оформляется командой.

## Последствия
- Мало кода, легко читать. Шину и outbox можно добавить позже без переписывания обработчиков.
- Нет гарантированной доставки событий между процессами — приемлемо в одном процессе (ADR-0005).
