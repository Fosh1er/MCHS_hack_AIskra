# 0004. DI без фреймворка: заглушки провайдеров + composition root

- **Статус:** Принято · **Дата:** 2026-09-26 · **Пункты плана:** 0.1

## Контекст
API-слой не должен знать о конкретных адаптерах (import-linter запрещает импорт `aiskra.bootstrap` из `modules.*.api`), но FastAPI-эндпоинтам нужны обработчики.

## Решение
- `modules/<m>/api/deps.py` объявляет `provide_x = provider_stub("m.X")` — функцию, которая падает с понятной ошибкой.
- `aiskra/bootstrap.py:wire()` делает `app.dependency_overrides[provide_x] = factory`. Фабрика может сама зависеть от `Depends(get_session)` для обработчиков с БД.
- Все сервисы процесса собираются в `build_services()` и лежат в `app.state.services`.

## Последствия
- Нет сторонней DI-библиотеки. Тесты подменяют зависимости тем же механизмом.
- Забытое связывание видно сразу: ошибка «не связана в composition root».
