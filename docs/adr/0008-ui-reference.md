# 0008. Эталон внешнего вида АРМ

- **Статус:** Предложено (ждёт подтверждения капитана) · **Дата:** 2026-09-26 · **Пункты плана:** 1.1, 1.3, 2.1, 2.2

## Контекст
Заказчик требует, чтобы карточка и реестр были на 100% похожи на оригинал (#679, #680). Источников два, и это **разные версии АРМ**:
- скриншоты стенда от 17.09.2026 (`СКРИНШОТ КАРТОЧКИ 112ГСИ.docx`, `СКРИНШОТ ДДСГСИ.docx`);
- инструкция 2507ГСИ со скриншотами 2019–2025 годов.

Различия: блок «Пострадавшие» (три кнопки против «Нет / Есть + количество»), строка заявителя (канал связи), вход (поле «номер АРМ», цвет кнопки), колонки журнала.

## Решение (предложение)
- **Раскладку, цвета и элементы брать со стенда 2026** — это текущая система, её узнают преподаватели. Токены — в `packages/ui-kit`.
- **Поведение и элементы, которых нет на скриншотах стенда, брать из инструкции:** количество пострадавших, окно «Список оповещаемых служб», «совпадение», канал связи, «Данные абонента», номер АРМ при входе (п. 0.3 плана).

## Последствия
Фронт и документация опираются на одно правило. Спорные элементы перечисляются в спецификации пункта 1.1.
