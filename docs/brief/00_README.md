## Суть задачи в трёх предложениях

Нужен веб-тренажёр в локальном контуре, имитирующий АРМ-112 и АРМ ДДС, с двумя учебными ролями под одной учёткой: оператор 112 принимает ИИ-вводную «заявителя» и заполняет карточку (адрес, заявитель, описание, тип по опросной карте, службы), диспетчер ДДС получает карточки потоком, принимает или отклоняет их, звонит старшему группы через симулятор IP-телефона и проставляет статусы реагирования. ИИ генерирует сценарии и эталоны, преподаватель их утверждает, проводит занятие и получает отчёт с ошибками, таймингом и грамматикой. Карточка и реестр должны выглядеть как в реальном АРМ; эндпоинт модели настраиваемый, на демо допустим внешний API.
