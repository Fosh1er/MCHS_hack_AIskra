# Консолидированные требования. Учебный тренажёр оператора 112 / диспетчера ДДС

Задача #9 ЛЦТ 2026. Заказчик: Департамент ГОЧСиПБ г. Москвы, ГБУ «Система 112».
Официальное название по ТЗ: «Учебное программное обеспечение для подготовки оператора ДДС города Москвы с использованием искусственного интеллекта».

Источники (приоритет сверху вниз при противоречиях, согласно #625 «ТЗ — первоисточник»):
1. ТЗ_ДГОЧСиПБ_финал_01092026ГСИ.docx (единственная версия).
2. Прямые ответы заказчика в чате (#683, #684, #690, #691, #701, #739, #740) и разъяснения модератора Str1fe (см. [06_Чат_заказчика_вопросы_и_ответы.md](06_Чат_заказчика_вопросы_и_ответы.md)).
3. Инструкция по заведению карточки (Памятка «Работа на АРМ-112») — [03_Карточка_112_и_бизнес-процесс.md](03_Карточка_112_и_бизнес-процесс.md).
4. Скриншоты АРМ ДДС, карточки 112, служб — [04_Интерфейс_АРМ_по_скриншотам.md](04_Интерфейс_АРМ_по_скриншотам.md).

Обозначения приоритета: **[M]** обязательно (must, без этого решение не соответствует ТЗ), **[S]** желательно (should, заказчик прямо ждёт или это критерий оценки), **[C]** опционально (could, бонус/опциональные модули ТЗ). Для каждого требования — источник.

## 13. Принятые допущения по открытым вопросам

| Вопрос | Допущение |
|---|---|
| «Мобильная версия» | Адаптивный веб-интерфейс, без нативного приложения |
| Доступ ДДС к аудио разговора 112 | Нет; ДДС работает только с карточкой |
| Голос заявителя | TTS-синтез из сгенерированного текста; текстовый режим — основной, голос — переключаемый |
| Железо/GPU заказчика | Конфигурируемый LLM-провайдер; демо на внешнем API; инструкция по локальному развёртыванию компактной модели на CPU/GPU |
| Обновление карточки при изменении обстановки | Комментарии к статусам без пересоздания карточки; повторные обращения — по инструкции 112 |
| Структура опросных карт по типам | Восстанавливаем по классификатору (признаки 1→3, доп. признаки) и скриншотам |
| Управление звонком в UI | Софтфон: ответить, удержание, завершить, перевод — без сброса заявителя как оцениваемого действия |
