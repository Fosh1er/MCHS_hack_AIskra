# Голосовой ввод оператора и диспетчера (п. 1.4, 2.3)

Как это работает:
1. В панели звонка нажимаете **«говорить»** и произносите реплику в трубку.
2. Нажимаете **«готово»**. Запись длиной до 30 с уходит на сервер тренажёра (`POST /api/v1/training/speech`).
3. Сервер передаёт её модели распознавания речи (Whisper) за OpenAI-совместимым `/v1/audio/transcriptions`.
4. Распознанный текст отправляется собеседнику как обычная реплика. Дальше всё как при вводе текстом: ИИ-заявитель отвечает, темы опроса засчитываются в автооценку.

Кнопка «говорить» появляется, только когда распознавание настроено. Без него остаётся текстовый ввод.

## Где запустить Whisper

| Вариант | Где | Когда |
|---|---|---|
| **Локально на GPU** (рекомендуется) | компьютер с NVIDIA, например RTX 4060, 8 ГБ | демо и контур заказчика: речь не покидает сеть |
| Локально на CPU | сервер тренажёра по ТЗ (6 ядер, без GPU) | модель поменьше, `Systran/faster-whisper-small`; реплика распознаётся за секунды |
| OpenRouter | внешний API | только демо и только с пополненным счётом: Whisper оплачивается по секундам аудио, бесплатных моделей распознавания нет ([документация](https://openrouter.ai/docs/guides/overview/multimodal/stt)) |

## Компьютер с RTX 4060: Speaches

[Speaches](https://speaches.ai/) — открытый сервер faster-whisper с OpenAI-совместимым API. Модель `deepdml/faster-whisper-large-v3-turbo-ct2` (MIT) занимает около 2–3 ГБ видеопамяти, так что RTX 4060 её тянет. Русскую реплику она распознаёт быстрее секунды.

1. **Подготовка.** Нужны драйвер NVIDIA и Docker с поддержкой GPU:
   - Windows: Docker Desktop на WSL 2, GPU в нём включён по умолчанию;
   - Linux: NVIDIA Container Toolkit.

   Проверка — команда `docker run --rm --gpus all nvidia/cuda:12.4.1-base-ubuntu22.04 nvidia-smi` должна показать видеокарту.
2. **Запуск** ([инструкция Speaches](https://speaches.ai/installation/)):
   ```bash
   docker run --detach --restart unless-stopped --publish 8000:8000 --name speaches \
     --volume hf-hub-cache:/home/ubuntu/.cache/huggingface/hub --gpus=all \
     ghcr.io/speaches-ai/speaches:latest-cuda
   ```
3. **Загрузка модели** (один раз, около 1,6 ГБ):
   ```bash
   SPEACHES_BASE_URL=http://localhost:8000 uvx speaches-cli model download deepdml/faster-whisper-large-v3-turbo-ct2
   ```
4. **Проверка** — на той же машине, с любой записью речи:
   ```bash
   curl -s http://localhost:8000/v1/audio/transcriptions -F "file=@проба.wav" -F "model=deepdml/faster-whisper-large-v3-turbo-ct2" -F "language=ru"
   ```
5. **Порт.** Откройте порт 8000 во входящих правилах брандмауэра для локальной сети и узнайте IP машины, например `192.168.31.20`.

## Подключение к тренажёру
В `.env` сервера тренажёра:

```
STT_KIND=openai_compatible
STT_URL=http://192.168.31.20:8000/v1
# STT_MODEL=deepdml/faster-whisper-large-v3-turbo-ct2   — по умолчанию
```

Перезапустите сервер. Адрес в локальной сети (10/8, 172.16/12, 192.168/16) считается внутренним: разрешение `allow_external` для него не нужно. Для OpenRouter: `STT_URL=https://openrouter.ai/api/v1`, `STT_MODEL=openai/whisper-large-v3`, ключ в `STT_API_KEY`, `AISKRA_AI_ALLOW_EXTERNAL=true`.

## Микрофон в браузере
Браузер даёт доступ к микрофону только странице по **https** или на **localhost**.
- **С той же машины**, по адресу http://localhost:5173, работает сразу.
- **Стенд в docker с TLS** (`https://…:8443`) тоже работает сразу.
- **Коллеги по локальной сети по http**, например `http://192.168.31.59:5173`, кнопку «говорить» увидят неактивной с подсказкой. Для демо можно запустить Chrome с флагом `--unsafely-treat-insecure-origin-as-secure=http://192.168.31.59:5173` или открыть стенд по https.

При первом нажатии браузер спросит разрешение на микрофон.

## Проверено
- **Unit-тесты:** адаптер отправляет запрос в формате multipart и читает текст ответа; при сбое модели возвращается ошибка сервиса; внешний адрес запрещён без `allow_external`, адрес в локальной сети разрешён.
- **Интеграционный тест:** эндпоинт возвращает `stt_disabled`, если модель не настроена, текст — если настроена, и 401 без входа.
- **В Chrome с фейковым микрофоном и заглушкой Whisper:**
  - «говорить» → «говорите… 00:02 — готово»;
  - на сервер ушёл `speech.webm` на 34 КБ;
  - реплика «Что у вас случилось? Назовите адрес.» отправлена заявителю;
  - заявитель ответил адресом.
- **Реальный Whisper на RTX 4060** не проверен: машины с GPU у разработчика нет.
