# Голос: ввод оператора (п. 1.4, 2.3) и голос собеседника (п. 3.6)

Как это работает:
1. В панели звонка нажимаете **«говорить»** и произносите реплику в трубку.
2. Нажимаете **«готово»**. Запись длиной до 30 с уходит на сервер тренажёра (`POST /api/v1/training/speech`).
3. Сервер передаёт её модели распознавания речи (Whisper) за OpenAI-совместимым `/v1/audio/transcriptions`.
4. Распознанный текст отправляется собеседнику как обычная реплика. Дальше всё как при вводе текстом: ИИ-заявитель отвечает, темы опроса засчитываются в автооценку.

Кнопка «говорить» появляется, только когда распознавание настроено. Без него остаётся текстовый ввод.

## Где запустить Whisper

| Вариант | Где | Когда |
|---|---|---|
| **Локально на GPU** (рекомендуется) | компьютер с NVIDIA, например RTX 4060, 8 ГБ | демо и контур заказчика: речь не покидает сеть |
| Локально на CPU | сервер тренажёра по ТЗ (6 ядер, без GPU) | модель поменьше, `Systran/faster-whisper-small`; реплика распознаётся за секунды |
| OpenRouter | внешний API | только демо и только с пополненным счётом: Whisper оплачивается по секундам аудио, бесплатных моделей распознавания нет ([документация](https://openrouter.ai/docs/guides/overview/multimodal/stt)) |

## Компьютер с RTX 4060: Speaches

[Speaches](https://speaches.ai/) — открытый сервер faster-whisper с OpenAI-совместимым API. Модель `deepdml/faster-whisper-large-v3-turbo-ct2` (MIT) занимает около 2–3 ГБ видеопамяти, так что RTX 4060 её тянет. Русскую реплику она распознаёт быстрее секунды.

1. **Подготовка.** Нужны драйвер NVIDIA и Docker с поддержкой GPU:
   - Windows: Docker Desktop на WSL 2, GPU в нём включён по умолчанию;
   - Linux: NVIDIA Container Toolkit.

   Проверка — команда `docker run --rm --gpus all nvidia/cuda:12.4.1-base-ubuntu22.04 nvidia-smi` должна показать видеокарту.
2. **Запуск** ([инструкция Speaches](https://speaches.ai/installation/)):
   ```bash
   docker run --detach --restart unless-stopped --publish 8000:8000 --name speaches \
     --volume hf-hub-cache:/home/ubuntu/.cache/huggingface/hub --gpus=all \
     ghcr.io/speaches-ai/speaches:latest-cuda
   ```
3. **Загрузка модели** (один раз, около 1,6 ГБ):
   ```bash
   SPEACHES_BASE_URL=http://localhost:8000 uvx speaches-cli model download deepdml/faster-whisper-large-v3-turbo-ct2
   ```
4. **Проверка** — на той же машине, с любой записью речи:
   ```bash
   curl -s http://localhost:8000/v1/audio/transcriptions -F "file=@проба.wav" -F "model=deepdml/faster-whisper-large-v3-turbo-ct2" -F "language=ru"
   ```
5. **Порт.** Откройте порт 8000 во входящих правилах брандмауэра для локальной сети и узнайте IP машины, например `192.168.31.20`.

## Подключение к тренажёру
В `.env` сервера тренажёра:

```
STT_KIND=openai_compatible
STT_URL=http://192.168.31.20:8000/v1
# STT_MODEL=deepdml/faster-whisper-large-v3-turbo-ct2   — по умолчанию
```

Перезапустите сервер. Адрес в локальной сети (10/8, 172.16/12, 192.168/16) считается внутренним: разрешение `allow_external` для него не нужно. Для OpenRouter: `STT_URL=https://openrouter.ai/api/v1`, `STT_MODEL=openai/whisper-large-v3`, ключ в `STT_API_KEY`, `AISKRA_AI_ALLOW_EXTERNAL=true`.

## Переключение режимов
Распознавание и синтез спрятаны за портами `STTPort` и `TTSPort`. У OpenRouter, Speaches и локальных серверов для проверки один OpenAI-совместимый протокол, поэтому адаптер тоже один на всех. Режим задаётся переменными в `backend/.env` и включается перезапуском сервера — **код не меняется**.

| Режим | Распознавание (оператор) | Голос (собеседник) | Переменные |
|---|---|---|---|
| **Без речи** (по умолчанию) | только текст | браузер | ничего |
| **Проверка на машине разработчика**, без ключей и Docker | faster-whisper на процессоре: `make dev-stt` | нейроголоса Piper: `make dev-tts` (или голос macOS: `make dev-tts-say`) | `STT_KIND=openai_compatible` `STT_URL=http://localhost:8200/v1` `TTS_KIND=openai_compatible` `TTS_URL=http://localhost:8100/v1` `TTS_FORMAT=wav`; голоса ролей для Piper: `TTS_VOICE=irina` `TTS_VOICE_FEMALE=irina` `TTS_VOICE_MALE=denis` `TTS_VOICE_BRIGADE=dmitri` `TTS_VOICE_SERVICE=irina` |
| **Демо на OpenRouter**, один ключ | Whisper large-v3-turbo | Gemini TTS с эмоцией | `AISKRA_AI_CONFIG_PATH=../config/ai.openrouter.yaml` `AISKRA_AI_ALLOW_EXTERNAL=true` `DEMO_LLM_API_KEY=<ключ>` `STT_KIND=openai_compatible` `TTS_KIND=openai_compatible` |
| **Контур заказчика** | Speaches, Whisper на GPU/CPU | Speaches, Piper | `STT_KIND` / `STT_URL`, `TTS_KIND` / `TTS_URL` — адреса Speaches |

**Про `make dev-tts`:**
- это нейроголоса Piper — те же, что у Speaches в контуре заказчика, на движке sherpa-onnx (Apache-2.0);
- голоса скачиваются при первом запуске в `~/.cache/aiskra/piper`, по 21 МБ в int8;
- в памяти занимают около 300 МБ, реплика синтезируется за 0,6–0,8 с;
- у ролей разные голоса: заявительница — irina, заявитель — denis, старший группы — dmitri;
- эмоция передаётся только темпом, как у Piper в контуре заказчика.

Лицензии голосов по карточкам моделей rhasspy/piper-voices:

| Голос | Лицензия | Использование |
|---|---|---|
| denis, dmitri | CC0 | можно везде |
| irina | «Unknown» (датасет RHVoice) | единственный женский голос; для проверки, в контур заказчика — после уточнения лицензии |
| ruslan | CC BY-NC-SA, некоммерческая | не используем |

У сценариев, созданных до п. 3.6, голоса заявителя в легенде нет. Тогда голос берётся по правилу генератора из имени («Кузнецов Алексей» — мужской): имена в сценариях — только из списка генератора.

**Про `make dev-stt`:**
- первый запуск скачивает модель faster-whisper small, около 480 МБ;
- в памяти она занимает около 800 МБ;
- русская фраза распознаётся за 1,4 с на Apple M-процессоре;
- лёгкий вариант — `cd backend && uv run --with faster-whisper python tools/dev_stt_whisper.py --model base`: около 145 МБ, русский распознаёт хуже.

## Микрофон в браузере
Браузер даёт доступ к микрофону только странице по **https** или на **localhost**.

- **Стенд в docker с TLS** (`https://…:8443`) — работает сразу.
- **Локальный стенд для коллег в сети:**
  1. Один раз выпустите сертификат на IP машины: `make dev-cert`. Он самоподписанный, на 30 дней, лежит в `.cert/` и в git не попадает.
  2. Запустите клиент: `make fe-dev-lan`.

  Dev-сервер будет отдавать `https://<IP>:5173` (http отключается). При первом заходе браузер предупредит о сертификате: «Дополнительно» → «Перейти на сайт». После этого микрофон доступен.

  Вернуть http: удалить `.cert/` или запустить клиент с `AISKRA_DEV_HTTP=1`.

При первом нажатии «говорить» браузер спросит разрешение на микрофон.

## Проверено
- **Unit-тесты:** адаптер отправляет запрос в формате multipart и читает текст ответа; при сбое модели возвращается ошибка сервиса; внешний адрес запрещён без `allow_external`, адрес в локальной сети разрешён.
- **Интеграционный тест:** эндпоинт возвращает `stt_disabled`, если модель не настроена, текст — если настроена, и 401 без входа.
- **HTTPS для сети:** по `https://192.168.31.59:5173` вход работает, `isSecureContext` = true, микрофон доступен.
- **В Chrome с фейковым микрофоном и заглушкой Whisper:**
  - «говорить» → «говорите… 00:02 — готово»;
  - на сервер ушёл `speech.webm` на 34 КБ;
  - реплика «Что у вас случилось? Назовите адрес.» отправлена заявителю;
  - заявитель ответил адресом.
- **Реальный Whisper на RTX 4060** не проверен: машины с GPU у разработчика нет.

## Голос собеседника (п. 3.6)
ИИ-заявитель говорит с эмоцией. Его состояние — напряжение, доверие, эмоция — меняется от того, как с ним говорит оператор ([спецификация 3.6](../../specs/3.6-emotional-voice.md)).

Как звучит реплика:
1. Текст ответа приходит сразу: по нему оператор заполняет карточку.
2. Звук панель запрашивает отдельно: `GET /api/v1/training/calls/{id}/messages/{mid}/audio`.
3. Сервер озвучивает реплику голосом роли (заявитель — женский или мужской голос из легенды, старший группы, диспетчер службы) и с подачей по состоянию заявителя у этой реплики.
4. Синтез не настроен или упал — панель озвучивает ту же реплику голосом браузера. Темп, высота и громкость и тогда следуют состоянию.

Одинаковая фраза с той же подачей синтезируется один раз. Кеш аудио ограничен `cache_mb` (по умолчанию 64 МБ).

| Вариант | Эмоция | Где | Как включить |
|---|---|---|---|
| **Голос браузера** (по умолчанию) | темп, высота, громкость | браузер | ничего |
| **OpenRouter, Gemini TTS** | стилем: «panicking caller, very fast, gasping…» | внешний API, только демо; **платно**, доли цента за реплику | `config/ai.openrouter.yaml`, в `.env`: `TTS_KIND=openai_compatible`, ключ — тот же `DEMO_LLM_API_KEY`, `AISKRA_AI_ALLOW_EXTERNAL=true` |
| **Speaches + Piper** | только темпом | контур заказчика, CPU | контейнер Speaches из раздела выше и модель `speaches-ai/piper-ru_RU-irina-medium` (есть denis, dmitri, ruslan); в `.env`: `TTS_KIND=openai_compatible`, `TTS_URL=http://<машина>:8000/v1` |
| **Голос macOS** (проверка без ключей и Docker) | только темпом | машина разработчика | `make dev-tts`; сервер тренажёра: `TTS_KIND=openai_compatible TTS_URL=http://localhost:8100/v1 TTS_FORMAT=wav` |

Остальные переменные:
- `TTS_MODEL`, `TTS_STYLE` (`google` / `openai` / `none`), `TTS_FORMAT` (`mp3` / `wav` / `pcm`);
- голоса: `TTS_VOICE` (по умолчанию), `TTS_VOICE_FEMALE`, `TTS_VOICE_MALE`, `TTS_VOICE_BRIGADE`, `TTS_VOICE_SERVICE`.

Эмоция передаётся параметром провайдера (`provider.options`), а не текстом, поэтому модель без инструкций не прочитает её вслух.

Звук играется по адресу своего сайта: CSP стенда не пускает `blob:` в медиа.

**Проверено:**
- **Unit-тесты:**
  - адаптер отправляет стиль в `provider.options` Google или OpenAI, при `none` — только темп;
  - PCM оборачивается в WAV;
  - сбой — ошибка сервиса;
  - кеш ограничен по байтам, одновременные запросы дают один синтез.
- **Интеграционный тест:** свой звонок — звук, чужой — 404, реплика оператора — 404, без входа — 401, синтез выключен — 422 `tts_disabled`.
- **Вживую на голосе macOS:**
  - синтез реплики — 0,6–0,7 с, повтор из кеша — 5 мс;
  - в Chrome панель играет серверный звук;
  - заглушка остановлена — та же реплика звучит голосом браузера.
- **Gemini TTS через OpenRouter не проверен:** нет пополненного ключа.

## Разговор без рук (п. 3.6, V3)
Переключатель **«без рук»** в панели звонка появляется, когда настроено распознавание. С ним микрофон слушает весь звонок:
1. Говорите как по телефону — фраза начинается и заканчивается сама. Конец фразы — 0,7 с тишины.
2. Фраза распознаётся и уходит заявителю.
3. Заговорили, пока заявитель говорит, — он замолкает (перебивание).
4. Сказали две фразы, пока он отвечает, — обе уйдут по очереди.

**Как устроено:**
- Индикатор: «слушаю фон», «слушаю», «собеседник говорит — можно перебить», «слышу вас…», «распознаю…».
- Первую секунду после включения микрофон слушает фон — в это время лучше помолчать.
- Чувствительность (высокая / сбалансированная / строгая) выбирается рядом с индикатором и запоминается в браузере.
- Голос собеседника из динамиков фразу не запускает: пока он звучит, порог выше. Распознанное эхо его реплики отбрасывается.
- «Титры», которые Whisper сочиняет на шуме («Продолжение следует…»), сервер выбрасывает.
- Микрофон закрывается после «завершить», при уходе со страницы и на время подсказок по кнопкам.
- На сервер уходят только готовые фразы, звук не хранится.

**С гарнитурой** работает лучше всего. **С колонками** выберите «строгую» чувствительность.

В отчёте занятия у карточки видно, как шёл разговор («голосом», «голосом без рук»). В голосовом режиме во время заполнения входит речь заявителя.

**Проверено:**
- **Chrome, в микрофон подан WAV с двумя фразами голосом macOS, распознаёт настоящий faster-whisper small:**
  - «Где вы находитесь?» и «Есть пострадавшие?» распознаны дословно, по 1,4 с;
  - ушли по очереди, заявитель ответил на обе.
- **Piper через сервер тренажёра:** три звонка из банка — «Кузнецов Алексей» говорит голосом denis, «Кузнецова Ирина» и «Новикова Ольга» — голосом irina; после грубости оператора темп ×1,15.
- **Живой Whisper нашёл два дефекта, которые заглушка скрывала:**
  - Первое слово терялось: запись начиналась по срабатыванию детектора. «Где вы находитесь?» превращалось в «вы находитесь.», и вопрос об адресе не засчитывался. Теперь звук пишется непрерывно, к фразе добавляется предзапись 0,4 с, а если оператор перебил собеседника — 0,9 с.
  - «Оставайтесь на линии» распознаётся как «доставайтесь на линии» или «доставайтесь на линия». Правила успокоения теперь ищут основу «на лини».
- Перебивание остановило звук заявителя.
- После «завершить» и на время подсказок микрофон закрыт.
- Детектор проверен отдельно: щелчок и эхо собеседника фразу не запускают, тихий слог фразу не рвёт.
- Живой микрофон и эхо из колонок в комнате не проверялись: Chrome, запущенный из автоматизации на macOS, не получает системного доступа к микрофону.
- Whisper через OpenRouter не проверялся — нет ключа. Адаптер тот же, формат multipart OpenRouter поддерживает.
