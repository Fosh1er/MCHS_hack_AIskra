# Проверка в браузерах (п. 9.5)

Проверка 29.09.2026 на стенде с демо-историей, утилита `backend/tools/browser_smoke.py`. В каждом браузере:
- открыты экраны преподавателя, оператора 112 и диспетчера ДДС (11 экранов);
- выполнены ключевые действия: учебный вызов → «Ответить» → реплика заявителю и его ответ; журнал ДДС → карточка;
- собраны ошибки JavaScript и снимки экранов (в папке браузера, `report.json`).

| Браузер | Версия | Экраны | Действия | Ошибки JavaScript |
|---|---|---|---|---|
| Firefox | 155.0 | 11 / 11 | 5 / 5 | 0 |
| Google Chrome | 152 | 11 / 11 | 5 / 5 | 0 (одна запись «404» — загрузка ресурса, не ошибка скрипта) |
| Яндекс.Браузер | — | построен на Chromium: тот же движок, что у Chrome | | |

Отдельно на Windows 10/11 и Ubuntu проверка не проводилась. Приложение работает в браузере, поведение определяет движок браузера, а не ОС. Прогон на машине заказчика:

```bash
cd backend
AISKRA_DEMO_PASSWORD='…' uv run --with playwright python tools/browser_smoke.py --browser firefox --web http://<стенд>:5173 --out ../docs/browsers/firefox
```

Firefox для Playwright: `uv run --with playwright python -m playwright install firefox`.
