# Сборка финальной презентации

Скрипты, которыми собрана финальная версия `АИскра_презентация_ЛЦТ2026.pptx` и `.pdf` (20.10.2026).

1. `shoot_final.py <папка>` — скриншоты новых функций со стенда `localhost:5173` в режиме `demo`: Playwright, нужен демо-вход.
2. `fill_final.py <рабочая папка>` — заполнение. В рабочей папке ожидаются:
   - `deck2/work.pptx` — исходная презентация плюс копии слайдов-образцов, сделанные `add_slide.py` из навыка pptx;
   - `shots2/` — скриншоты.

   Результат:
   - `final.pptx` — с анимированной гифкой;
   - `final_poster.pptx` — первый кадр вместо гифки, для PDF.
3. `render.py <pptx> <папка>` — PDF и превью слайдов через LibreOffice.

Обязательные слайды 7–11 шаблона ЛЦТ стоят в конце, в приложении: формат шаблона сохранён, на защите их можно пропустить (правила организаторов).
