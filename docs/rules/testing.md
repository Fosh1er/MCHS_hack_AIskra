# Правила тестирования

- **unit** (`backend/tests/unit`): домен, обработчики с фейками портов, адаптеры на MockTransport. Без БД и сети, < 1 с на файл.
- **integration** (`backend/tests/integration`): эндпоинты через `TestClient`. Фикстуры `conftest.py`:
  - БД — файл SQLite + `create_all`;
  - пользователи `admin` / `teacher` / `student` с паролем `PASSWORD`;
  - `admin` — клиент, вошедший администратором; `app_client()` — ещё один «браузер»; `login(c, "student")`.

  Для функций, специфичных для PostgreSQL, — отдельная отметка и прогон в compose.
- **Каждый новый эндпоинт:** успех под нужной ролью и 403 под чужой. Тест `test_every_api_route_requires_session` сам проверяет, что без входа эндпоинт возвращает 401.
- **Каждая команда:** позитивный сценарий + нарушение правила (`DomainError`).
- **Импорт справочников:** тест на реальных файлах из `data/` (счётчики и выборочные значения) + тест идемпотентности (повторный импорт ничего не меняет).
- **ИИ:** только `FakeLLM`. Тест кеша — вызов модели ровно один раз.
