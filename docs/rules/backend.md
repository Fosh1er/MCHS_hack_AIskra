# Правила backend

- **Python 3.12, строгая типизация** (`mypy --strict` зелёный). Публичные функции — с аннотациями, без `Any` без причины.
- **Домен:** `@dataclass`, value objects `frozen=True`, инварианты проверяются в конструкторе или методах, ошибки — `DomainError` с `code`.
- **Команда = один файл** `application/commands/<verb_noun>.py`: `Command` + `Result` (dataclass) + `Handler`. Запрос — аналогично в `queries/`.
- **Обработчик получает зависимости в `__init__`** (порты), вызывается `await handler(cmd)`. Внутри никаких `fastapi.Request`, сессий SQLAlchemy и HTTP.
- **Репозиторий:** порт в `application/ports/`, реализация в `infrastructure/repositories.py`. Возвращает доменные объекты, а не ORM-модели.
- **Чтение для экранов и реестров:** SQL или ORM-выборка сразу в DTO, с пагинацией (`limit` ≤ 200) и индексами под фильтры.
- **API:** pydantic-схемы в `api/schemas.py`, отдельно от DTO. Префикс `/api/v1/<module>`. Коды ошибок — через исключения, не через `HTTPException` в обработчиках.
- **Время:** в БД `timestamptz` (UTC). В домене используйте порт `Clock` там, где время влияет на логику (таймеры, нормативы).
- **Миграции:** `uv run alembic revision --autogenerate -m "кратко"` → проверить руками → не редактировать применённые.
- **Логи:** `logging.getLogger(__name__)`, без ПДн (телефоны, ФИО) в сообщениях. Пароли и токены — `field(repr=False)`, никогда не логируются и не пишутся в аудит.
- **Права:** каждый эндпоинт — `require(Permission.X)`; значимое действие — запись `AuditRecorder` в обработчике команды (ADR-0010).
- **Поиск по тексту:** ключ `shared.text.search_key(...)` сохраняется при записи и сравнивается через `LIKE`; `func.lower()` не используйте — он зависит от локали БД.
- **Время из БД** — через `platform.types.as_utc(...)`: SQLite теряет часовой пояс.
- **Импорт данных** — идемпотентный (upsert по естественному ключу), с отчётом: сколько добавлено, обновлено, пропущено и почему.
