# Правила git

- **Ветки:** `feat/<пункт плана>-<кратко>` (например `feat/0.1-1.1`), `fix/<кратко>`. В `main` — только через PR.
- **Коммиты** — Conventional Commits на русском: `feat(dictionaries): импорт классификатора`, `fix(ai): ...`, `docs(adr): ...`, `test: ...`, `chore: ...`.
- **Один коммит — одна логическая единица.** Проверки зелёные до коммита.
- **Не коммитим:** `.env`, ключи, реальные ПДн, большие бинарники вне `data/source/`.
- **Стоп-код 29.09.2026 23:59 МСК:** после него сданные ветки не трогаем, работа продолжается в новой ветке.
- **Трассировка:** в теле коммита — `Refs: <пункт> (<ID требований>)`, например `Refs: 0.2 (R0.2-09)`. Статусы в `specs/<пункт>.md` обновляются в том же коммите.
