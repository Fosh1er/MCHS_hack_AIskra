# Правила frontend

- **UI только из `@smena112/ui-kit`** (токены, `.arm-*` для эмулятора АРМ, `.cab-*` для кабинетов). Новые цвета и шрифты не вводим. Если чего-то не хватает — компонент добавляется в ui-kit.
- **Карточка и реестр** повторяют АРМ заказчика (ADR-0008): раскладка, подписи, горячие клавиши. Учебные надстройки визуально отделены (полоса «ТРЕНАЖЁР», док справа).
- **Данные:** запросы — `useQuery`, команды — `useMutation` в `src/shared/api/<module>.ts`. Типы — из OpenAPI бэкенда (в будущем `openapi-typescript`).
- **Статус** = иконка + подпись + цвет, никогда не только цвет. Подписи из данных — только через JSX (никакого `dangerouslySetInnerHTML`).
- **АРМ** — десктоп (≥ 1366 px), клавиатура в первую очередь. Кабинеты — адаптивные до 375 px.
- **Тексты интерфейса** — по-русски.
