# Правила ИИ-слоя

- **Вызов модели** — только `router.for_task(AITask.X).complete(messages, schema=..., cache_scope=...)`.
- **Структурированный ответ** — pydantic-модель в `schema=`. Парсинг, повтор при невалидном JSON и ошибки — забота адаптера.
- **Промпты** — в `aiskra/ai/prompts/<task>/<version>.md` (появятся с п. 3.x). Меняя промпт, повышайте `prompt_version` задачи в конфиге — кеш автоматически обойдёт старые ответы.
- **Кеш:**
  - оценка текста (`judge`) — `exact`, temperature 0;
  - реплики актёров — `task` со `scope` = id сценария (+ раскрытые факты);
  - генерация — `off`.
- **Никогда:**
  - не хардкодить URL и ключи;
  - не ставить вызов модели в синхронный путь интерфейса, если можно асинхронно;
  - не отдавать модели реальные ПДн.
- **Детерминированная логика раньше ИИ:** маршрутизация служб, тип, признаки, тайминги считаются правилами (классификатор). ИИ — для естественного языка и свободного текста.
- **Тесты:** через `FakeLLM(fixtures={task: ...})`, без сети. Адаптеры HTTP тестируются на `httpx.MockTransport`.
