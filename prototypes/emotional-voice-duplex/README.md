# Voice Agent — OpenRouter STT/LLM/TTS

Веб-прототип голосового AI-агента на OpenRouter. Браузер слушает микрофон, локально определяет паузу, отправляет короткий аудиосегмент на STT, получает потоковый ответ модели и озвучивает его через TTS.

## Запуск

Требования: Node.js 18.18+ и ключ OpenRouter.

```powershell
Copy-Item .env.example .env
notepad .env
npm install
npm run dev
```

В `.env` укажи:

```env
OPENROUTER_API_KEY=sk-or-v1-...
```

Открой [http://localhost:3000](http://localhost:3000) в Chrome или Edge, разреши микрофон и нажми «Начать разговор».
Для отдельной проверки озвучки можно нажать «Тест TTS» — микрофон и баланс STT для этого не нужны.

## Архитектура

- `POST /api/stt` → `https://openrouter.ai/api/v1/audio/transcriptions`.
- `POST /api/chat` → потоковый `https://openrouter.ai/api/v1/chat/completions`.
- `POST /api/tts` → `https://openrouter.ai/api/v1/audio/speech`.
- API-ключ используется только на сервере.
- Browser VAD сначала калибрует фон, использует адаптивный порог и гистерезис, требует несколько голосовых кадров для старта и завершает аудиосегмент только после устойчивой паузы.
- Чувствительность VAD можно менять в интерфейсе: высокая, сбалансированная или строгая; выбранный профиль сохраняется в браузере.
- Одна реплика агента озвучивается одним TTS-запросом с блокировкой очереди; начало новой пользовательской реплики останавливает текущую озвучку.
- Кнопка «Тест голоса» позволяет выбрать голос и отдельно проверить эмоциональный режим TTS.
- LLM получает выбранный сценарий 911 и текущую динамическую тональность; ответ начинается технической строкой `TONE|...`, которая скрывается от оператора.
- Система оценивает реплику оператора: спокойные подтверждения снижают напряжение и повышают доверие, грубость и давление делают звонящего более тревожным.
- TTS использует Google Gemini 3.8 Flash Lite TTS с фиксированным голосом `Zephyr` и получает расширенную директиву эмоции, темпа, громкости, срочности, дыхания, доверия и сотрудничества.

## Переменные

- `OPENROUTER_MODEL` — быстрая модель агента (`google/gemini-3.1-flash-lite`).
- `OPENROUTER_REASONING_EFFORT` — уровень рассуждений; для голосового режима используется `none`.
- `OPENROUTER_MAX_TOKENS` — верхняя граница длины реплики; по умолчанию `120`.
- `OPENROUTER_STT_MODEL` — модель транскрибации.
- `OPENROUTER_TTS_MODEL` — модель синтеза речи (`google/gemini-3.8-flash-lite-tts`).
- `OPENROUTER_TTS_VOICE` — фиксированный голос TTS (`Zephyr`).
- `OPENROUTER_SITE_URL` и `OPENROUTER_APP_NAME` — необязательные метаданные для OpenRouter.

По умолчанию LLM — `google/gemini-3.1-flash-lite`, а TTS — `google/gemini-3.8-flash-lite-tts` с голосом `Zephyr`.

Текущие OpenRouter-модели STT/TTS и доступные голоса могут отличаться; при необходимости замени значения в `.env`.
