## 4. Решения
- **Тип файла — по содержимому.** Расширение легко подменить; сигнатура отсекает исполняемые файлы под видом PDF.
- **Поиск выдержек — лексический** (основы слов по первым пяти буквам, доля слов запроса в выдержке). Для десятка документов этого хватает и не нужна модель эмбеддингов; RAG на эмбеддингах — P2.
- **Файл — на диске, текст — в БД.** Текст нужен для поиска и промптов; файл отдаётся как есть. PDF открывается встроенным просмотрщиком браузера, для DOCX и XLSX показывается текст — конвертер в PDF не нужен.
- Выдержки идут в промпт только при подключённой модели; в офлайн-режиме генерация шаблонная, как раньше.

## 5. Критерии приёмки
- [x] Преподаватель загружает инструкцию и памятки, обучающийся читает и ищет по ним.
- [x] Скрытый материал обучающемуся не виден и не открывается.
- [x] Отмеченные материалы попадают в запрос генерации.

## 6. Отклонения, долги
- Резервная копия (5.2) сохраняет записи материалов и их текст, но не сами файлы: они в томе `materials`. Для полного переноса нужно скопировать и том.
- Картинки из DOCX (скриншоты интерфейса в инструкции) в текстовом просмотре не показываются — их видно после скачивания.
