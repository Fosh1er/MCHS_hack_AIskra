## 1. Пункт плана
> **3.2. Генерация сценариев и эталонов — P0.** Выбор строки классификатора по категориям и сложности → LLM генерирует легенду заявителя (ФИО, статус, телефоны, адрес из справочника, объект, описание своими словами, пострадавшие, доп. признаки, «шум» по уровню сложности) + эталонную карточку (тип, признаки, ответы опросной карты, службы через `resolve_services`, ключевые фразы описания) + эталонные действия ДДС + эталонные регламентные фразы. Structured output (JSON schema). Пакетная генерация для банка сценариев; загрузка учебных билетов из датасета как seed.
