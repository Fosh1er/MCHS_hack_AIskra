# 2.3 — Симулятор IP-телефона ДДС

- **Приоритет:** P0 (имитация) / P2 (реальный SIP) · **Статус:** ✅ имитация; ⏳ SIP (P2)
- **Ветка:** `feat/3.2-3.3-1.4-2.3-ai` · **Зависит от:** [2.2](2.2-dds-card.md), [3.3](3.3-dialog-agents.md)

## 1. Пункт плана
> **2.3. — P0 / P2.** Софтфон в интерфейсе, стилизованный под РТУ Т16Р (экран, DSS-клавиши служб/бригад, линии): исходящий звонок старшему группы → ИИ-«старший группы» отвечает (доклад о выезде, прибытии, ходе работ); входящий звонок-доклад от бригады; звонок заявителю; журнал звонков; фиксация факта и времени звонка для оценки. Опционально: WebRTC/SIP.
