## 4. Решения
- **Денормализация, а не кеш.** Журнал ДДС упирался в поиск каждой карточки службы по UUID-ключу; копия времени сохранения в строке службы (пишется один раз при сохранении) убрала это без инвалидации кеша.
- **Опрос вместо WebSocket** (ADR-0005): восстановление после сбоя — повтор запросов и сессии; требование «переподключение WebSocket» выполнено по сути.
- **Работа в фоновом окне**: повторы и опрос не ставятся на паузу без фокуса — АРМ ДДС часто открыт в фоне.

## 5. Критерии приёмки
- [x] Цели ТЗ по отклику, сессиям, записи и отчёту выполнены на объёме года.
- [x] Сбой API не теряет карточку и не требует перезагрузки страницы.

## 6. Отклонения, долги
- Замер на SQLite; на PostgreSQL — повтор тем же скриптом на сервере (M7).
- Поиск по тексту в журнале ДДС ≈100 мс на 18 тыс. карточек (без триграммного индекса).
- Повтор сохранения карточки проверен ручным сбоем на чтении; сбой ровно в момент сохранения вручную не воспроизводился.
