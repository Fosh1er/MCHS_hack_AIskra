# 5.1 — Кабинет обучающегося

- **Приоритет:** P0 · **Статус:** ⏳ в работе
- **Ветка:** `feat/5.1-5.2-cabinets` · **Фронт:** `frontend/src/pages/student/`
- **Зависит от:** [4.2](4.2-sessions.md), [4.3](4.3-reports.md), [1.3](1.3-journal.md)

## 1. Пункт плана
> **5.1. Кабинет обучающегося — P0.** Назначенные занятия/модули; вход в занятие → эмулятор (роль 112 или ДДС); таймер; после занятия — свои результаты, разбор ошибок, рекомендации; история; справочная база.

## 2. Требования
| ID | Требование |
|---|---|
| R5.1-01 | Список назначенных занятий: запланированные, идущее, прошедшие; роль в каждом |
| R5.1-02 | Вход в идущее занятие открывает эмулятор своей роли (журнал 112 или АРМ своей ДДС) |
| R5.1-03 | Таймер занятия в баннере эмулятора |
| R5.1-04 | Свои результаты по занятию: карточки, балл, время против норматива, разбор ошибок по критериям, комментарии преподавателя |
| R5.1-05 | Рекомендации по слабым критериям |
| R5.1-06 | История: прошедшие занятия со средним баллом; динамика баллов |
| R5.1-07 | Справочная база: классификатор происшествий с поиском, справочник служб |
| R5.1-08 | Комментарий «Вернуть на доработку» виден автору карточки (долг 1.3) |
