# 5.2 — Панель администратора

- **Приоритет:** P0 (учётки, аудит) / P1 (остальное) · **Статус:** ⏳ в работе
- **Ветка:** `feat/5.1-5.2-cabinets` · **Фронт:** `frontend/src/pages/admin/`
- **Зависит от:** [0.3](0.3-auth-rbac-audit.md), [0.2](0.2-data-model.md), [1.2](1.2-address-map.md)

## 1. Пункт плана
> **5.2. Панель администратора — P0 (учётки, аудит) / P1 (остальное).** Пользователи и роли, группы, блокировка; журнал аудита с фильтрами; состояние сервисов (health-checks БД, ИИ-провайдер, телефония); настройки: эндпоинт модели, тайминг по умолчанию, параметры бэкапа; кнопка бэкапа/восстановления (pg_dump); импорт классификатора и справочников; логи.

## 2. Требования
| ID | Требование |
|---|---|
| R5.2-01 | Пользователи: поиск, фильтры роли и статуса, создание, правка ФИО, роли и номера оператора |
| R5.2-02 | Блокировка и разблокировка, смена пароля |
| R5.2-03 | Группы обучающихся: создание, переименование, удаление, состав с ролью и профилем ДДС; группа выбирается при создании занятия (долг 4.2) |
| R5.2-04 | Журнал аудита с фильтрами (готов в 0.3) — в меню администратора |
| R5.2-05 | Состояние сервисов: БД, ИИ-провайдеры по задачам, телефония, кеш |
| R5.2-06 | Настройки: тайминг и пороги занятия по умолчанию, параметры бэкапа; модели ИИ — просмотр (правятся в `config/ai.yaml`) |
| R5.2-07 | Резервная копия: создать, список, скачать; восстановление |
| R5.2-08 | Импорт классификатора, справочников и адресов кнопкой, с отчётом |
| R5.2-09 | Логи приложения: последние записи с фильтром уровня |
