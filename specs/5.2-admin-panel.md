## 4. Решения
- **Копия логическая, а не pg_dump.** Выгрузка рабочих таблиц в сжатый JSON через ORM одинаково работает на PostgreSQL и SQLite и не зависит от совпадения версий pg_dump и сервера. Справочники в копию не входят: их даёт импорт из `data/`. Для полной копии PostgreSQL на сервере — `docker compose exec db pg_dump -U aiskra aiskra > backup.sql`.
- Восстановление требует слова-подтверждения, завершает все сессии и пишется в аудит после замены данных, иначе запись пропала бы вместе с журналом.
- Эндпоинты и ключи моделей ИИ не хранятся в БД (ADR-0003): панель показывает назначение моделей, правка — в `config/ai.yaml` и `.env`.
- Группа хранит роль участника на занятиях и профиль ДДС: преподаватель назначает группу одним выбором (закрыт долг 4.2).

## 5. Критерии приёмки
- [x] Администратор заводит пользователей и группы, блокирует, меняет пароль.
- [x] Видит состояние сервисов, меняет тайминг по умолчанию, делает и восстанавливает копию.
- [x] Все изменения — в аудите.

## 6. Отклонения, долги
- Автоматическое копирование по расписанию не сделано: копия — кнопкой или запросом `POST /system/backups` из cron.
- Логи — только текущего процесса, в памяти; после перезапуска история пуста (долгое хранение — журнал контейнера).
- Правка эндпоинта модели из интерфейса не сделана намеренно (секреты вне БД).
- Файлы учебных материалов (4.4) в копию не входят — только записи и текст; файлы лежат в томе `materials`.
