# 4.5 — Продвинутая аналитика преподавателя

- **Приоритет:** P1 (сверх плана; решение команды 27.09) · **Статус:** ✅
- **Ветка:** `feat/teacher-analytics`
- **Основания:** `docs/research/Подготовка_персонала_112_и_ЕДДС.md` — пункты 1, 3, 4, 5 раздела «Предложения» и смена норматива карточки на 75 с.

## 1. Задача
Облегчить преподавателю работу с обучающимися и формирование заданий по практике подготовки персонала 112 и ЕДДС:
- профиль обучающегося по всем занятиям — ПС 12.002, функции C/03 (оценка готовности) и C/04 (контроль качества);
- «норматив / факт» по времени — ПП РФ № 1931, п. 9 «р»; форма 1/112 (приказ МЧС № 192);
- разбор занятия с характерными недостатками — ГОСТ Р 22.7.01, п. 3.12.3;
- подбор задания по слабым местам — ПС 12.002, функция C/05 (тренинги по выявленным трудностям).

## 3. Типичная ошибка
Одинаковое замечание на разных карточках сводится в одну строку: без перечня после двоеточия, пояснений в скобках и чисел. Например, «номер дома не совпадает (эталон 37)» и «(эталон 7)» — одна ошибка (`domain/analytics.py::error_key`).

## 4. Проверено вручную
На копии локальной базы проведены два занятия: `op1` работал чисто, `op2` — с ошибками адреса, описания и служб, одна карточка заполнялась 78 с.
- «Аналитика»: 8 из 9 карточек в нормативе, 90-й процентиль, по обучающимся и занятиям.
- Профиль `op2`: описание −32 и службы −18 относительно группы, ошибки с номерами карточек, непройденные группы.
- «Индивидуальное задание»: форма заполнена — «Пожары» со средним баллом 72 плюс две новые группы, сложность 2, фокус инструктажа, один участник.
- Разбор: пять недостатков, превышение 78,1 с при нормативе 75, лучшие результаты.
- Телефон 375 px — без горизонтальной прокрутки.

## 5. Ограничения
- Время ДДС до п. 4.5 считалось только в баллах. Теперь его считает адаптер фактов, поэтому оно есть и для старых карточек.
- Порог на графике профиля — 70 (по умолчанию): профиль охватывает занятия с разными порогами.
- Не сделано из предложений: готовность к допуску по шкале МЧС (п. 2), покрытие классификатора матрицей по группе (п. 6), отчёт по трудовым действиям профстандарта (п. 8), журнал учёта занятий и стажировка (пп. 9–10).
