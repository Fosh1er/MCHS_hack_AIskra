# 3.3 — Ролевые агенты диалога

- **Приоритет:** P0 (заявитель текстом) / P1 (голос, старший группы) · **Статус:** ✅ (голос — синтез речи браузера; распознавание речи — нет)
- **Ветка:** `feat/3.2-3.3-1.4-2.3-ai` · **Решения:** [ADR-0003](../docs/adr/0003-ports-adapters-ai.md), [ADR-0006](../docs/adr/0006-ai-response-cache.md)

## 1. Пункт плана
> **3.3. Ролевые агенты диалога — P0 / P1.** Агент «Заявитель» (держит легенду, отвечает на вопросы оператора, не выдаёт лишнего, эмоциональный фон по сложности); агент «Старший группы реагирования» (доклады о выезде/прибытии/работах по таймлайну сценария); агент «Диспетчер смежной службы». Ограничение: не раскрывать эталон.

## 2–3. Требования и трассировка
| ID | Требование | Реализация | Проверка | Статус |
|---|---|---|---|---|
| R3.3-01 | Заявитель отвечает только на заданный вопрос, из легенды | `domain/actors.py:applicant_reply` (темы вопросов → поля легенды, раскрытые темы в `Call.revealed`); с моделью — `application/actors.py:Actors.applicant`, промпт `applicant_actor/v1.md` | `unit/test_training_domain.py::test_applicant_answers_only_what_asked`; `unit/test_training_ai.py::test_applicant_prompt_hides_reference` | ✅ |
| R3.3-02 | Не раскрывать эталон | В промпт и офлайн-ответы идёт только публичная часть легенды (без `reference_*`, кодов, служб) | `::test_applicant_never_leaks_reference`, `::test_applicant_prompt_hides_reference` | ✅ |
| R3.3-03 | Эмоциональный фон по сложности | `legend.emotion` (1 «спокойно» … 5 «паника»), первая реплика по сложности | `::test_humanize_and_story` | ✅ |

| R3.3-07 | Кеш ответов актёров | `cache: task` со `scope` = сценарий + раскрытые темы (ADR-0006) | конфиг | ✅ |

## 6. Долги
- Распознавание речи оператора (STT) — нет: оператор печатает реплики. Озвучка ответов — синтез речи браузера (`CallPanel`, переключатель «голос»).
