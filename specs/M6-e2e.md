# M6 — Сквозной сценарий

- **Приоритет:** P0 · **Статус:** ✅ на локальном стенде (docker compose — на сервере, M7)
- **Ветка:** `feat/m6-e2e`
- **Опирается на:** 1.1–1.5, 2.1–2.4, 3.2–3.4, 4.1–4.4, 5.1–5.2

## 1. Веха
> **M6. Сквозной сценарий (28.09 вечер):** «вводная → карточка 112 → очередь ДДС → статусы → отчёт преподавателя» на стенде.

## 2. Шаги цепочки
| ID | Шаг | Кто |
|---|---|---|
| E1 | Стенд поднят одной командой: справочники, адреса, банк сценариев, учётки ролей, группа, материалы | администратор |
| E2 | Преподаватель создаёт смешанное занятие группой (операторы 112 и диспетчеры ДДС), карточки для ДДС — от операторов занятия, и запускает его | преподаватель |
| E3 | Оператору 112 поступает учебный вызов в категориях занятия; ИИ-заявитель отвечает на вопросы | оператор 112 |
| E4 | Оператор заполняет и сохраняет карточку 112; службы подбираются автоматически | оператор 112 |
| E5 | Карточка появляется в очереди ДДС той службы, за которую работает диспетчер занятия | диспетчер ДДС |
| E6 | Диспетчер принимает карточку и ведёт статусы до «Работы завершены», созванивается со старшим группы | диспетчер ДДС |
| E7 | Преподаватель видит работу обоих в мониторинге, завершает занятие, оценивает все карточки | преподаватель |
| E8 | Отчёт по занятию: оператор и диспетчер, баллы, ошибки, время; экспертная правка; обучающиеся видят свои результаты | преподаватель, обучающиеся |
