## 4. Решения
- Связь хранится столбцом у подчинённой карточки (`main_card_id`), а не отдельной таблицей: в АРМ связь одноуровневая.
- Баннер открывается сам только при повторном звонке (`CallView.repeat_of`): в учебном банке сценарии повторяются вместе с номером заявителя, и баннер на каждом таком совпадении мешал бы занятию (нашёл e2e). В остальных случаях — оранжевая кнопка «совпадение» у адреса, как в АРМ (`image61`).
- Привязку можно сделать и в черновике — баннер появляется, пока оператор заполняет новую карточку.
- Совпадения ищутся в Python по 300 последним карточкам за сутки: телефоны в карточке — свободный текст в разном формате.

## 5. Критерии приёмки
- [x] Повторный звонок с того же номера → баннер с исходной карточкой → «привязать» → в журнале «Связи».
- [x] Без привязки оценка карточки по повторному звонку — «не зачтено» с пояснением.
- [x] Занятия без настройки `repeat_share` работают как раньше.

## 6. Отклонения, долги
- Тип «Дополнительный звонок от заявителя» не выделен отдельно: в классификаторе его нет; карточка по повторному звонку оценивается по привязке и времени.
- «Сделать главной» (`image67`) — нет: главная — первая карточка.
