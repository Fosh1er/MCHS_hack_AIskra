# СМЕНА-112 · UI Kit

Библиотека стилей и React-компонентов для тренажёра «СМЕНА-112».
1. **АРМ-скин** (`.arm-*`) — точная копия интерфейса АРМ-112 и АРМ-ДДС ГБУ «Система 112». ТЗ требует реалистичной имитации интерфейса.
2. **Кабинеты** (`.cab-*`) — преподаватель, администратор, обучающийся. Они выдержаны в той же стилистике: ТЗ требует единую стилистику всех компонентов.

Палитра и формы сняты **пипеткой со скриншотов** из материалов заказчика (`СКРИНШОТ ДДСГСИ.docx`, `СКРИНШОТ КАРТОЧКИ 112ГСИ.docx`), доминирующий цвет по областям. Скриншоты сделаны при масштабе браузера 80%, поэтому размеры в токенах соответствуют тому, что оператор видит на экране.

## Структура

```
ui-kit/
├── index.css            # все стили одним импортом (tokens → base → arm → cabinet)
├── tokens/tokens.css    # дизайн-токены: цвет, типографика, отступы, размеры АРМ
├── css/base.css         # сброс, шрифт, иконки, утилиты
├── css/arm.css          # АРМ-скин (.arm-*)
├── css/cabinet.css      # кабинеты (.cab-*) и графики (.viz-*, .spark)
├── icons/icons.json     # единый источник путей иконок (Material Icons, Apache 2.0)
├── icons/icons.js       # спрайт для статичных HTML (генерируется: npm run icons)
├── js/viz.js            # спарклайн и линейный график для статичных страниц
├── react/               # React-компоненты (TypeScript, strict)
│   ├── util.ts          # cx(), Status, formatTimer(), normStatus()
│   ├── Icon.tsx
│   ├── primitives.tsx   # Button, IconButton, Segmented, StatusPill, Tag, Avatar, Banner, Meter
│   ├── arm.tsx          # ArmApp, TrainingBar, PhoneField, CardTimer, Chip, Questionnaire, ServiceBar/ServiceTab,
│   │                    # StatusHistory, StatusEditor, JournalRow, Dock, IncomingCall, Transcript, QueueItem …
│   ├── cabinet.tsx      # AppShell, Sidebar, TabBar, Topbar, SimClock, Card, StatTile, StudentTile, EventFeed, ServiceHealth
│   └── charts.tsx       # Sparkline, LineChart (прицел + подсказка + таблица-двойник)
└── preview/             # HTML-экраны и smoke-тест React-компонентов
```

## Подключение в React (Vite)

```ts
// main.tsx
import '@fontsource/roboto/300.css';
import '@fontsource/roboto/400.css';
import '@fontsource/roboto/500.css';
import '@fontsource/roboto/700.css';        // шрифт офлайн — контур без интернета
import '@smena112/ui-kit/index.css';

import { ArmApp, TrainingBar, ServiceBar, ServiceTab, StatusEditor, StudentTile } from '@smena112/ui-kit';
```

```tsx
<ServiceBar expanded onToggleExpand={toggle} stack={<ServiceTab name="Поселение Вороновское" status="11:23 Принята" mine onEdit={openEditor} />}>
```

Команды:
- `npm run typecheck` — проверка типов (strict);
- `npm run smoke` — рендер компонентов в `preview/_smoke/*.html` для визуальной сверки;
- `npm run icons` — пересобрать спрайт после правки `icons.json`.

## Правила

1. **АРМ копируем, а не «улучшаем».** Раскладка, цвета, подписи, горячие клавиши — как в оригинале. Эмулятор не блокирует ошибочные действия: их фиксирует оценщик.
2. **Учебные надстройки отделены визуально.** Тренажёрная полоса с оранжевой линией и меткой «ТРЕНАЖЁР», док софтфона и очереди справа. Оператор не спутает их с реальным АРМ.
3. **Статус — это иконка + подпись + цвет, никогда не цвет отдельно.** Относится к `StatusPill`, плиткам, ленте, индикаторам.
4. **Контраст.** Вторичный текст — `--text-muted` (#5f6468, 5,2:1) на панелях и `--text-muted-canvas` (#4a4f53, 5,2:1) на холсте. Белый на оранжевом и стальном (≈3,2:1) — только крупный жирный текст, как в оригинале.
5. **Графики** (dataviz):
   - одна ось Y, линия 2 px, hairline-сетка;
   - порог — отдельная линия с подписью;
   - прицел и подсказка при наведении и фокусе клавиатуры;
   - у каждого графика есть таблица-двойник (кнопка «Таблица»);
   - серия — бренд-синий `#157dbd`, проверен валидатором палитры (PASS на `#efefef`);
   - ширина viewBox = ширине контейнера, поэтому подписи осей не масштабируются.
6. **Подписи из данных** вставляются только через `textContent` / JSX, без `innerHTML`.
7. **Адаптив.** Кабинеты работают до ширины телефона: боковое меню сменяется нижним таб-баром (удалённый контроль из ТЗ). АРМ — только десктоп (от 1366 px), как рабочее место оператора.
